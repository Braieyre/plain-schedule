# 普通课程表

> 就是个课程表。

一个 Android 课程表 App。导入教务系统的课表 PDF，然后看课表。没了。

**1.47 MB** · 冷启动 **0.35 秒** · **零权限** · **零网络请求** · 无账号 · 无推送 · 无广告

---

## 一、先说说课表 App 是怎么变成今天这样的

课程表是个多简单的东西。一周七列，一天十几行，格子里写课名和教室。
这件事在纸上做了几百年，一张 A4 就够，还能贴在墙上。

然后它被搬进手机，开始长东西。

你点开图标，先看五秒开屏广告——右上角那个「跳过」要等三秒才亮，而且做得比周围暗一点，
让你找它得多花半秒。广告放完进首页，课表在哪？在第二屏。第一屏是信息流：
考研倒计时、四六级报名、兼职招聘、"同校 3km 内有人想认识你"。

你划到课表，发现今天的课上面压着一条横幅，说你有 3 条未读消息。
点开是系统通知：签到得积分，积分换皮肤。你退出来，右下角冒出一个悬浮球，
在你想点周三的课时挡住了周三。

你想关掉推送，进设置。设置里有二十几项，推送开关在「消息与互动」的第三层，
关掉之后弹窗问你「确定不再接收重要通知吗？可能错过考试提醒哦」，
默认按钮是「再想想」。

而这一切，是为了让你看一眼**周三下午在哪上课**。

它还要你的权限。要通讯录——因为要"找到同班同学"。要位置——因为要"推荐附近的自习室"。
要存储——因为要"缓存图片"。要开机自启、要后台常驻、要读取应用列表。
你装了一个课表，收获了一个常驻内存、持续上传、按时推送的东西。

**这不是功能太多。这是它的商业模式要求它这样。**

一个免费 App 要赚钱，就得有广告位；要有广告位，就得有停留时长；
要有停留时长，就不能让你三秒钟看完课表就走。
**所以"让你快速看完课表离开"这件事，和它的收入是直接冲突的。**

课表本身不赚钱，课表是获客渠道。你不是用户，你是流量。
产品经理每个季度要交的 KPI 是 DAU 和时长，不是"用户看课表的速度"。
于是每一次迭代，它都必然、也只能，朝着更重、更黏、更吵的方向走。

这不是哪个程序员懒惰或者哪个设计师品味差。**这是结构性的。**
只要它靠你的注意力赚钱，它就一定会来抢你的注意力。

## 二、所以我们的想法很简单

**一个工具应该在你需要它的时候出现，做完事就消失。**

它不该有主页，因为它只有一个页面。
它不该有推送，因为课表不会突然变。
它不该联网，因为你的课表就在你手机里。
它不该有账号，因为它不需要知道你是谁。

这不是什么高深的理念，这只是**工具本来的样子**。锤子不会在你不用它的时候震动。

我们没有商业模式，所以我们不需要你的时长。
**这个 App 最理想的使用体验，是你打开它，两秒钟后关掉。**

它叫「普通课程表」。这个名字是认真的——
我们不想做一个超级的、智能的、全能的课表。**我们想做一个普通的。**

## 三、它长什么样

### 核心功能

- **PDF 导入**——选中教务系统导出的课表 PDF，自动解析成结构化课表
- **周视图**——左右滑动翻周，离开本周时周数变橙并浮出「回到本周」
- **课程详情**——点格子看周次、节次、时间、教室、老师、考核方式
- **手动增删改**——解析不了？自己录入。课名、周几、节次、周次（区间多选）、教室、老师
- **非本周课程**——可选显示，灰卡呈现，方便看整学期的排布
- **上课时间自定义**——每节课的起止时刻都能改
- **换肤**——三套配色、深浅色跟随系统、相册背景图
  （配背景图时有卡片透明度和背景蒙层双滑块，保证文字始终可读——这是必需项不是装饰）

### 它明确不做的事

不做上课提醒，不做桌面小组件，不做课表分享，不做社交，不做发现页，不做积分，不做皮肤商店。

有些是我们觉得不值得，有些是我们还没想清楚怎么做才不膨胀。
**如果哪天加了功能，它得先证明自己值得占用你的注意力。**

## 四、数字

这些都是在真机上实测出来的，不是估算，你可以自己复现：

| 项 | 值 | 怎么来的 |
|---|---|---|
| 安装包 | **1.47 MB** | `./gw :app:assembleRelease` 后看文件大小 |
| 冷启动 | **350 ms** | `adb shell am start -W`，读 `TotalTime` |
| 权限声明 | **0** | `AndroidManifest.xml` 里没有任何 `<uses-permission>` |
| 网络请求 | **0** | 没有网络权限，想联网也联不了 |
| 第三方依赖 | **只有 2 类** | Jetpack Compose 和 `kotlinx-serialization-json`。没有网络库、没有数据库、没有 DI、没有图片库 |
| 埋点 / SDK | **0** | 没有统计、没有崩溃上报、没有推送 |

**关于零权限**：这一条你不用信我们，装完自己去系统设置里翻应用权限，那一栏是空的。
选背景图走的是系统相册选择器，选文件走的是系统文件选择器——
这两个都是把选中的那一个文件交给 App，**不需要授予存储权限**。

**关于数据**：所有数据存在应用私有目录里的两个 JSON 文件，几 KB。
没有服务器，我们不知道你是谁、上什么课、在哪个学校。卸载即清空。

## 五、安装与使用

### 装

从 [Releases](../../releases) 下载 APK，传到手机点开安装。

系统大概率会拦一下，提示「禁止安装未知来源应用」——按提示进设置，
给**你用来打开这个文件的那个 App**（微信 / 文件管理器 / 浏览器）开启「允许安装未知应用」，
返回重试即可。小米 / 红米（HyperOS）可能会多确认一次。

### 用

1. 从教务系统下载你的课表 PDF，存到手机
2. 打开 App → 左上角菜单 → **导入 PDF 课表**
3. 选中 PDF → 等解析 → 预览确认 → **设置开学日期**
   （可以直接选「今天是第几周」反推，比翻日历快）
4. 完成

### ⚠️ 关于兼容性，必须说在前面

**这个解析器目前只认一种教务系统导出的 PDF 格式。**

它识别的是 `星期一…星期日` 表头、`(1-2节)` 这种节次写法、
`/场地:` `/教师:` `/考核方式:` 这套字段标签。国内高校教务系统有好几家厂商，
格式各不相同。**如果你们学校用的不是这一种，大概率解析失败。**

解析失败时，页面会把从 PDF 里读到的**原始文字**显示出来并允许复制。
把那段文字提个 [Issue](../../issues)，我们看看能不能支持。

**即使解析不了，手动加课的功能是完整的**，当普通课表用没有任何问题。

## 六、技术

```
core/    纯 Kotlin/JVM —— PDF 文字提取 + 课表解析 + 领域模型 + 周次计算
app/     Android —— Compose UI + 存储 + 设置
```

`core` 不依赖 Android，可以用普通 JUnit 在 JVM 上直接拿真实 PDF 跑测试。
**这是整个项目最重要的验证杠杆**：解析逻辑不用上设备就能回归。

### 为什么自己写 PDF 解析器

因为 PdfBox 之类的库会让 APK 大十倍。

这个 App 只需要从 PDF 里拿到「文字 + 坐标」，用不上完整的 PDF 渲染能力。
所以 `core/src/main/kotlin/.../pdf/PdfText.kt` 是一个约 800 行的极简提取器，
只依赖 JDK 自带的 `java.util.zip.Inflater`：

- 线性扫描 `N 0 obj … endobj` 建对象表，**刻意跳过 xref**——对损坏或增量更新的 PDF 更健壮
- 内容流词法器 + 图形/文本状态机，处理 `cm` / `q` / `Q` / `Tm` / `Tj` / `TJ` 等操作符
- 文本解码三档：`Identity-H`/`UCS2` 走 UTF-16BE → 有 `/ToUnicode` 就解析 CMap → 兜底 Latin-1
- 页面 `/Rotate` 归一化到视图坐标

课表解析（`parse/ScheduleParser.kt`）**不靠几何切格子**，而是靠锚点：
七个「星期X」表头定位列带，轴向按方差自适应（规避页面旋转带来的坐标歧义），
列内文本按行序拼接后用 `(N-M节)` 正则切分——
跨行折断的长课名由"拼接"天然消解，不需要单独处理换行。

### 其他选择

- **不用 Room**：数据只有几 KB，两个 JSON 文件足够，省掉注解处理器和数据库初始化
- **不用 Hilt/Dagger**：一个由 Activity 持有的普通状态对象就够，省掉一整套框架的启动开销
- **不用 Navigation 库**：一个 `sealed interface` + `when` 就是全部路由
- **不用图片加载库**：只有一张背景图，`BitmapFactory` 加 `inSampleSize` 降采样

这些加起来，就是 1.47 MB 和 350 ms 的来源。**轻量不是优化出来的，是不加东西加出来的。**

### 构建

需要 JDK 17 和 Android SDK（compileSdk 35）。

```bash
./gw :core:test          # 解析层测试，不需要设备
./gw :app:assembleDebug  # 出 APK
```

`gw` 是 `gradlew` 的薄包装，用来处理 JDK 路径不在 `PATH` 上的情况；
直接用 `./gradlew` 也行。
